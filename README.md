# Student Marks Analysis Project

This project analyzes student marks from a CSV file.  
It calculates **total marks, average, maximum, minimum**,  
and identifies **students scoring above average**.  
It also visualizes the data using a **line graph**.

---

## Graph

![Total Marks Graph](total_marks_graph.png)

> This graph shows the **total marks of each student**.  
> The peaks represent students who scored the highest marks.

---

## High Scorers

Students who scored **above average marks** are saved in the CSV file:

`high_scorers.csv`

You can download or view it to see the **list of top-performing students**.

---

## Files in this project

- `Student.csv` → Original student marks data  
- `analysis.py` → Python script for analysis and visualization  
- `total_marks_graph.png` → Graph of total marks  
- `high_scorers.csv` → List of students scoring above average

---
